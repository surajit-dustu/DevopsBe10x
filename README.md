# Pocketwise

A lightweight personal finance dashboard built with plain HTML, CSS, and JavaScript. Transactions and budgets are stored in the browser on this device.

## Run locally

```sh
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Included

- Monthly income, expense, savings, spending, and cash-flow summaries
- Quick transaction entry, filtering, and deletion
- Editable category budgets and account balance cards
- CSV transaction import with column mapping and duplicate detection
- CSV export
- Responsive layout for desktop and mobile

This prototype does not include sign-in, bank connections, or a backend. Browser storage is not a substitute for secure account-backed financial data storage.
